# ShoeFit

ShoeFit: A New Dataset and Dual-image-stream DiT Framework for Virtual Footwear Try-On

[Project Page](https://colorful-liyu.github.io/ShoeFit/) · [Paper](assets/ShoeFit.pdf) · [Dataset](https://github.com/colorful-liyu/MVShoes-clean)

ShoeFit is a dual-image-stream DiT framework for virtual footwear try-on, with Multi-view Conditioning and LayeredRefAttention.

The MVShoes-clean release contains 6,151 triplets, with 5,351 training samples and 800 test samples. Dataset access is provided by application for non-commercial academic research.
